# 🤖 Webots Maze Robot — Autonomous Navigation

An autonomous maze-solving robot simulation built in **Webots**, a professional open-source robotics simulator. The robot navigates through a maze environment using sensor-based decision making.

---

## ✨ Features

- Autonomous maze navigation
- Sensor-based obstacle detection and avoidance
- Real-time simulation in Webots environment
- Configurable maze layouts

---

## 🚀 How to Run

### Prerequisites
- [Webots](https://cyberbotics.com/) (free download)

### Steps
1. Extract `webots-maze.zip`
2. Open Webots
3. File → Open World → select the `.wbt` world file
4. Click the **Play** button to start the simulation
